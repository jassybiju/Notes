# DSA

Follow this order instead of trying to learn every pattern at once.

1. **Fundamentals:** Arrays, Strings, Hashing, Two Pointers, Sliding Window
2. **Searching and Sorting:** Binary Search, Intervals, Sorting, Prefix Sum
3. **Linear Data Structures:** Linked Lists, Stacks, Queues, Monotonic Stack
4. **Recursion:** Recursion, Backtracking, Subsets, Permutations
5. **Trees and Heaps:** DFS, BFS, BST, Heap, Top K
6. **Graphs:** BFS, DFS, DSU, Topological Sort, Shortest Paths
7. **Dynamic Programming:** 1D, 2D, Knapsack, Subsequences, Advanced DP
8. **Advanced Topics:** Greedy, Bit Manipulation, Trie, Segment Tree
